# VHS Tap

Tap NFC-enabled VHS tapes to instantly play movies on Jellyfin. A Node.js + Express server that bridges your physical 3D printed VHS collection with your Jellyfin media server.

**Author:** [8bits1beard LLC](https://github.com/8bits1beard-io)
**Repository:** https://github.com/8bits1beard-io/VHS-Tap

## Overview

This project lets you create a retro VHS collection experience with modern technology. Each 3D printed VHS tape has an NFC tag embedded in it. When you tap the tape with your phone, it displays movie information and provides a direct link to start playback in Jellyfin.

### Features

- 📼 NFC token validation and scanning
- 🎬 Jellyfin server integration
- 🖼️ Browse your entire Jellyfin library as a poster grid when assigning tapes, with an "on a tape" badge on movies already mapped
- 🔄 One-click Jellyfin library rescan from the admin panel (picks up newly added movies)
- 📲 QR code on every tape card for quickly writing its URL to an NFC tag
- 🎭 Automatic movie metadata from OMDB on tape creation (posters, ratings, cast, plot, awards)
- 🔐 Randomized NFC tokens by default to prevent URL farming (custom tokens still allowed)
- 🎨 Retro-styled admin panel and scan interface
- 🗃️ SQLite database for VHS tape/movie mappings
- 📱 Mobile-friendly scan page
- 🔒 Environment-based configuration (no hardcoded credentials)

## Quick Start

### Prerequisites

- Node.js v16 or higher
- A running Jellyfin server
- (Optional) OMDB API key for rich movie metadata

### Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/8bits1beard-io/VHS-Tap.git
   cd vhs-tap
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your Jellyfin URL, API key, and OMDB key
   ```

4. **Initialize the database:**
   ```bash
   npm run init-db
   ```

5. **Add your logo (optional):**
   ```bash
   cp /path/to/your/logo.png public/logo.png
   ```

6. **Start the development server:**
   ```bash
   npm run dev
   ```

7. **Access the application:**
   - Admin Panel: http://localhost:3000
   - Health Check: http://localhost:3000/health

## API Endpoints

- `GET /api/config` - Get public configuration (Jellyfin URL, app version)
- `POST /api/scan` - Validate NFC token and trigger movie playback
- `GET /api/tapes` - List all VHS tapes
- `GET /api/tapes/:id` - Get specific VHS tape
- `POST /api/tapes` - Create new VHS tape mapping (token optional — a random one is generated if omitted; OMDB metadata is fetched automatically)
- `PUT /api/tapes/:id` - Update VHS tape mapping (re-fetches metadata if the movie changes)
- `DELETE /api/tapes/:id` - Delete VHS tape mapping
- `GET /api/tapes/search/movies?q=...` - Search Jellyfin movies; omit `q` to browse the whole library (admin auth)
- `POST /api/tapes/library/refresh` - Trigger a Jellyfin library scan (admin auth)
- `POST /api/tapes/metadata/backfill` - Fetch OMDB metadata for any tapes missing it (admin auth)

## How It Works

1. **Add a tape**: In the admin panel, browse your Jellyfin library and pick a movie. A random, hard-to-guess token is generated by default (you can set your own), and OMDB metadata is fetched automatically.
2. **Program the tag**: Each tape card shows a QR code of its scan URL (`https://your-domain.com/scan?token=<token>`) — scan it with your phone to grab the URL, then write it to the NFC tag.
3. **Scanning**: When someone taps the NFC tag with their phone:
   - The phone opens the scan URL in the browser
   - The page fetches the movie info (with the stored OMDB metadata) from your server
   - User sees the full movie card and a "Watch Now" button
   - Clicking the button opens the movie in Jellyfin (auto-playback can start it on an active session)
